# Math Owl - Learn Addition

A delightful educational mini-game that teaches children aged 4-7 how to add
numbers, guided by a friendly owl mentor.

## How to play

1. **Meet Professor Hoot** — the owl introduces addition step by step
2. **Watch the demo** — see apples, stars, and teddy bears being counted together
3. **Answer questions** — tap the right answer from the colorful buttons
4. **Get praise** — confetti and encouragement for every correct answer
5. **Keep going** — three levels of increasing difficulty

## Levels

| Level | Name | Questions |
|-------|------|-----------|
| 1 | First Steps | 1+1, 2+1, 3+1 |
| 2 | Getting Bigger | 2+2, 3+2, 4+1 |
| 3 | Counting Fun | Visual counting with fruits, toys, and stars |

## Features

- Animated owl mentor with speech bubbles and typewriter text
- Smooth animations powered by Framer Motion
- Positive-only feedback — wrong answers trigger guided counting, never criticism
- Sound effects generated in-browser (Web Audio API, no audio files)
- Fully responsive — works on phones, tablets, and desktops
- Large tap targets designed for small fingers
