# Calm Moment

A calming micro-app for your daily emotional reset. Select your mood, receive a personalized motivational message, and listen to procedurally generated calming music.

## Features

- Google authentication
- Mood-based personalized quotes (48 unique messages)
- Procedurally generated calming music via Web Audio API
- Mood-adaptive music (different styles for each emotional state)
- Session tracking with mood, quote, and completion data
- Smooth page transitions and soothing animations
- Responsive mobile-first design
- PWA-ready (installable on mobile)

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- Framer Motion (animations)
- Web Audio API (procedural music generation)
- Vite (build tool)
